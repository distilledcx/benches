# CreepJS

[CreepJS](https://abrahamjuliot.github.io/creepjs/) in Chrome 155 on an Android 16 Distilled cloud phone that identifies as a Google Pixel 7, captured October 17, 2026. Screenshots are full-resolution captures of the phone screen.

## Bot score

CreepJS rates the browser on three scales in its Headless section.

| Scale | Score |
| --- | --- |
| Headless | 0% |
| Stealth | 0% |
| Like headless | 31% |

The like-headless scale counts 16 loose traits. The 5 it flagged here are no plugins, no MIME types, the PDF viewer off, light mode, and the default `ActiveText` colour. Android Chrome reports all five out of the box. See `00-headless-score.png` and `09-like-headless-detail.png`.
