# Distilled benches

Results from public browser benchmarks, run on Distilled cloud phones.

| Bench | What's here |
| --- | --- |
| [Stealth Bench v2](stealth-bench-v2/) | Per-visit outcomes, protocol, exclusions, retries, charts and the scripts that build them |

Site names are left out. Results are keyed by the benchmark's own task ids.
